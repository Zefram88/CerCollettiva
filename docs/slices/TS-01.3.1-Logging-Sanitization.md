- **Owner**: Security Team
- **Stakeholder**: CTO, Security Engineer

## Descrizione
Modificare il logger in energy/mqtt/manager.py per non includere l'intero payload dei messaggi, ma solo metadati (es. device_id, timestamp).

## Obiettivo Tecnico
Sanitizzare i log per evitare l'esposizione di dati sensibili mantenendo solo le informazioni necessarie per il debugging e il monitoring.

## Implementazione Dettagliata

### File Target
- `energy/mqtt/manager.py`

### Modifiche Richieste

#### Prima (Vulnerabile)
```python
def publish_measurement(device_id, value, timestamp=None):
    payload = {
        'device_id': device_id,
        'value': value,
        'timestamp': timestamp or datetime.now().isoformat()
    }
    
    # VULNERABILITÀ: Logging payload completo
    logger.info(f"Publishing measurement: {payload}")
    
    # Pubblicare messaggio MQTT
    client.publish(f"devices/{device_id}/measurements", json.dumps(payload))
    
    return True

def handle_device_status(device_id, status, metadata):
    payload = {
        'device_id': device_id,
        'status': status,
        'metadata': metadata
    }
    
    # VULNERABILITÀ: Logging payload completo
    logger.info(f"Device status update: {payload}")
    
    # Aggiornare stato dispositivo
    client.publish(f"devices/{device_id}/status", json.dumps(payload))
    
    return True
```

#### Dopo (Sicuro)
```python
def publish_measurement(device_id, value, timestamp=None):
    payload = {
        'device_id': device_id,
        'value': value,
        'timestamp': timestamp or datetime.now().isoformat()
    }
    
    # SICURO: Logging solo metadati
    logger.info(f"Publishing measurement for device {device_id}")
    
    # Pubblicare messaggio MQTT
    client.publish(f"devices/{device_id}/measurements", json.dumps(payload))
    
    return True

def handle_device_status(device_id, status, metadata):
    payload = {
        'device_id': device_id,
        'status': status,
        'metadata': metadata
    }
    
    # SICURO: Logging solo metadati
    logger.info(f"Device {device_id} status updated to {status}")
    
    # Aggiornare stato dispositivo
    client.publish(f"devices/{device_id}/status", json.dumps(payload))
    
    return True
```

## Test di Accettazione

### Test 1: Sanitizzazione Log
```python
def test_log_sanitization():
    device_id = 1
    value = 123.45
    
    publish_measurement(device_id, value)
    
    # Verificare che i log non contengano il valore
    log_content = open('logs/mqtt.log').read()
    assert str(value) not in log_content
    assert f'device {device_id}' in log_content
```

def test_metadata_preserved():
