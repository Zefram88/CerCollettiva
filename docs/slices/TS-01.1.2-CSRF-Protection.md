## Descrizione
Rimuovere @csrf_exempt e implementare la protezione CSRF standard in energy/views/dashboard_views.py e documents/views.py.

## Obiettivo Tecnico
Eliminare le esenzioni CSRF e implementare la protezione standard per prevenire attacchi Cross-Site Request Forgery.

## Implementazione Dettagliata

### File Target
- `energy/views/dashboard_views.py`
- `documents/views.py`

### Modifiche Richieste

#### Prima (Vulnerabile)
```python
# energy/views/dashboard_views.py
@csrf_exempt
def update_device_status(request):
    # VULNERABILITÀ: CSRF exemption senza validazione alternativa
    if request.method == 'POST':
        device_id = request.POST.get('device_id')
        status = request.POST.get('status')
        # ... logica aggiornamento
    return JsonResponse({'status': 'success'})

# documents/views.py
@csrf_exempt
def upload_document(request):
    # VULNERABILITÀ: CSRF exemption senza validazione alternativa
    if request.method == 'POST':
        file = request.FILES.get('document')
        # ... logica upload
    return JsonResponse({'status': 'success'})
```

#### Dopo (Sicuro)
```python
# energy/views/dashboard_views.py
def update_device_status(request):
    # SICURO: Protezione CSRF standard
    if request.method == 'POST':
        device_id = request.POST.get('device_id')

        # ... logica aggiornamento
    return JsonResponse({'status': 'success'})

# documents/views.py

    # SICURO: Protezione CSRF standard
```

## Test di Accettazione

### Test 1: Richiesta POST Senza Token CSRF Respinta
```python
def test_csrf_protection():
    # Test richiesta POST senza token CSRF
    response = client.post('/dashboard/update/', {
        'device_id': 1,
        'status': 'active'
    })
    assert response.status_code == 403
```

### Test 2: Richiesta POST Con Token CSRF Accettata
```python
def test_csrf_protection_with_token():
    # Ottenere token CSRF
    csrf_token = client.get('/dashboard/').cookies['csrftoken'].value
    
    # Test richiesta POST con token CSRF
    response = client.post('/dashboard/update/', {
        'device_id': 1,
        'status': 'active',
        'csrfmiddlewaretoken': csrf_token
    })
    assert response.status_code == 200
```

### Test 3: Upload Documento Senza Token CSRF Respinto
```python
def test_document_upload_csrf_protection():
```
