## Descrizione
Implementare la verifica della proprietà dell'utente in energy/views/device_views.py per le viste di dettaglio, modifica e cancellazione.

## Obiettivo Tecnico
Aggiungere la verifica `user=request.user` alle query per garantire che solo il proprietario possa accedere ai propri dispositivi.

## Implementazione Dettagliata

### File Target
- `energy/views/device_views.py`

#### Prima (Vulnerabile)

        # ... logica modifica

## Test di Accettazione

### Test 1: Accesso Non Autorizzato Bloccato
```python
def test_device_unauthorized_access():
    user1 = User.objects.create_user('user1')
    user2 = User.objects.create_user('user2')
    device = Device.objects.create(name='Test Device', user=user1)
    
    # Test accesso non autorizzato
    client.force_login(user2)
    response = client.get(f'/devices/{device.id}/')
    assert response.status_code == 404
```

### Test 2: Accesso Autorizzato Consentito
```python
def test_device_authorized_access():
    user = User.objects.create_user('user')
    device = Device.objects.create(name='Test Device', user=user)
    
    # Test accesso autorizzato
    client.force_login(user)
    response = client.get(f'/devices/{device.id}/')
    assert response.status_code == 200
```
