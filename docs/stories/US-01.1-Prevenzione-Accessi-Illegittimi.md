# User Story 1.1: Prevenzione Accessi Illegittimi (Broken Access Control)

## Informazioni Generali
- **ID**: US-01.1
- **Titolo**: Prevenzione Accessi Illegittimi (Broken Access Control)
- **Epic**: EPIC-01 Security Hardening
- **Priorità**: CRITICA
- **Stato**: COMPLETED
- **Sprint**: Sprint 1
- **Story Points**: 8
- **Owner**: Security Team
- **Stakeholder**: CTO, Security Engineer

## Descrizione
As a user, I want to be sure that only I can access my own devices and data, so that my information remains private and secure.

## Problema
Il sistema attualmente non verifica la proprietà dei dispositivi e dei dati, permettendo a qualsiasi utente autenticato di accedere a dispositivi di altri utenti. Questo rappresenta una vulnerabilità critica di sicurezza.

## Soluzione
Implementare la verifica della proprietà dell'utente in tutte le viste che gestiscono dispositivi e dati sensibili, garantendo che solo il proprietario possa accedere alle proprie risorse.

## Acceptance Criteria

### Criterio 1: Verifica Ownership Device
- **Given** un utente autenticato
- **When** tenta di accedere a un dispositivo di un altro utente
- **Then** riceve un errore 404/403
- **And** non può visualizzare i dati del dispositivo

### Criterio 2: Verifica Ownership Dashboard
- **Given** un utente autenticato
- **When** tenta di accedere alla dashboard di un altro utente
- **Then** riceve un errore 404/403
- **And** non può visualizzare i dati della dashboard

### Criterio 3: Verifica Ownership Documenti
- **Given** un utente autenticato
- **When** tenta di accedere a documenti di un altro utente
- **Then** riceve un errore 404/403
- **And** non può visualizzare i documenti

### Criterio 4: Verifica Ownership API
- **Given** un utente autenticato
- **When** tenta di accedere alle API di un altro utente
- **Then** riceve un errore 404/403
- **And** non può modificare i dati

## Test Cases

### Test 1: Accesso Non Autorizzato Device
```python
def test_device_unauthorized_access():
    user1 = User.objects.create_user('user1')
    user2 = User.objects.create_user('user2')
    device = Device.objects.create(name='Test Device', user=user1)
    
    client.force_login(user2)
    response = client.get(f'/devices/{device.id}/')
    assert response.status_code == 404
```

### Test 2: Accesso Autorizzato Device
```python
def test_device_authorized_access():
    user = User.objects.create_user('user')
    device = Device.objects.create(name='Test Device', user=user)

    response = client.get(f'/devices/{device.id}/')
    assert response.status_code == 200
```
