# User Story 1.3: Salvaguardia dei Dati Sensibili (Data Exposure & File Upload)

## Informazioni Generali
- **ID**: US-01.3
- **Titolo**: Salvaguardia dei Dati Sensibili (Data Exposure & File Upload)
- **Epic**: EPIC-01 Security Hardening
- **Priorità**: CRITICA
- **Stato**: PENDING
- **Sprint**: Sprint 1
- **Story Points**: 8
- **Owner**: Security Team
- **Stakeholder**: CTO, Security Engineer

## Descrizione
As a system administrator, I want to ensure that sensitive data is never exposed in logs and that only safe files can be uploaded, so that I can maintain compliance and system integrity.

## Problema
Il sistema attualmente espone dati sensibili nei log e non valida i file caricati, rappresentando un rischio per la privacy e la sicurezza del sistema.

## Soluzione
Implementare la sanitizzazione dei log per evitare l'esposizione di dati sensibili e aggiungere validazione robusta per i file caricati, garantendo che solo file sicuri possano essere processati.

## Acceptance Criteria

### Criterio 1: Sanitizzazione Log
- **Given** un log entry
- **When** viene generato
- **Then** non contiene dati sensibili
- **And** include solo metadati necessari

### Criterio 2: Validazione File Upload
- **Given** un file caricato
- **When** viene processato
- **Then** viene validato per tipo e dimensione
- **And** solo file sicuri sono accettati

### Criterio 3: Protezione Dati Sensibili
- **Given** dati sensibili nel sistema
- **When** vengono processati
- **Then** non vengono esposti nei log
- **And** sono protetti da accessi non autorizzati

### Criterio 4: Compliance
- **Given** il sistema in produzione
- **When** viene auditato
- **Then** rispetta le normative privacy
- **And** mantiene l'integrità dei dati

## Test Cases

### Test 1: Sanitizzazione Log
```python
def test_log_sanitization():
    device_id = 1
    value = 123.45
    
    publish_measurement(device_id, value)
    
    # Verificare che i log non contengano il valore
    log_content = open('logs/mqtt.log').read()
    assert str(value) not in log_content
    assert f'device {device_id}' in log_content
```

### Test 2: Validazione File Upload
```python
def test_file_upload_validation():
    # Test file consentito
    with open('test.pdf', 'rb') as f:
        response = client.post('/documents/upload/', {'document': f})
        assert response.status_code == 200
    
    # Test file non consentito
    with open('malicious.exe', 'rb') as f:
        response = client.post('/documents/upload/', {'document': f})
        assert response.status_code == 400
```

### Test 3: Protezione Dati Sensibili
```python
def test_sensitive_data_protection():
    user = User.objects.create_user('user')
    device = Device.objects.create(name='Test Device', user=user)
    
    # Verificare che i dati sensibili non siano nei log
    log_content = open('logs/application.log').read()
    assert user.password not in log_content
    assert device.api_key not in log_content
```
