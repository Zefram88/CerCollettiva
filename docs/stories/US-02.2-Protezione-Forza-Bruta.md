# User Story 2.2: Protezione da Attacchi di Forza Bruta e Abuso

## Informazioni Generali
- **ID**: US-02.2
- **Titolo**: Protezione da Attacchi di Forza Bruta e Abuso
- **Epic**: EPIC-02 Advanced Security
- **Priorità**: ALTA
- **Stato**: PENDING
- **Sprint**: Sprint 2
- **Story Points**: 5
- **Owner**: Security Team
- **Stakeholder**: CTO, Security Engineer

## Descrizione
As a system administrator, I want to limit the number of requests a single user can make, so that the service is protected from denial-of-service attacks and abuse.

## Problema
Il sistema attualmente non ha limitazioni sul numero di richieste che un utente può effettuare, rendendo l'applicazione vulnerabile ad attacchi DoS e abuso del servizio.

## Soluzione
Implementare un sistema di rate limiting che limiti il numero di richieste per IP e per utente, proteggendo il sistema da attacchi di forza bruta e abuso.

## Acceptance Criteria

### Criterio 1: Rate Limiting per IP
- **Given** un IP che effettua richieste
- **When** supera il limite stabilito
- **Then** riceve un errore 429
- **And** le richieste successive sono bloccate

### Criterio 2: Rate Limiting per Utente
- **Given** un utente autenticato
- **When** supera il limite stabilito
- **Then** riceve un errore 429
- **And** le richieste successive sono bloccate

### Criterio 3: Protezione Endpoint Sensibili
- **Given** endpoint sensibili
- **When** vengono chiamati
- **Then** hanno limiti più restrittivi
- **And** sono protetti da abuso

### Criterio 4: Configurazione Flessibile
- **Given** diversi tipi di endpoint
- **When** vengono configurati
- **Then** possono avere limiti diversi
- **And** la configurazione è flessibile

## Test Cases

### Test 1: Rate Limiting per IP
```python
def test_ip_rate_limiting():
    # Test richieste normali
    for i in range(50):
        response = client.get('/api/devices/')
        assert response.status_code == 200
    
    # Test superamento limite
    for i in range(60):
        response = client.get('/api/devices/')
        if i >= 100:
            assert response.status_code == 429
```

### Test 2: Rate Limiting per Utente
```python
def test_user_rate_limiting():
    user = User.objects.create_user('user')
    client.force_login(user)
    
    # Test richieste normali
    for i in range(50):
        response = client.get('/api/devices/')
        assert response.status_code == 200
    
    # Test superamento limite
    for i in range(60):
        response = client.get('/api/devices/')
        if i >= 100:
            assert response.status_code == 429
```

### Test 3: Protezione Endpoint Sensibili
```python
def test_sensitive_endpoint_protection():
    # Test endpoint sensibili con limiti più restrittivi
    for i in range(10):
        response = client.post('/api/login/')
        if i >= 5:  # Limite più restrittivo
            assert response.status_code == 429
```

### Test 4: Configurazione Flessibile
```python
def test_flexible_configuration():
    # Test che diversi endpoint possano avere limiti diversi
    assert get_rate_limit('/api/devices/') == 100
    assert get_rate_limit('/api/login/') == 5
    assert get_rate_limit('/api/upload/') == 10
```
